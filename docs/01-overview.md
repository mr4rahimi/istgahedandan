# ایستگاه دندان — نمای کلی پروژه

> این سند برای این نوشته شده که هر وقت کار را از صفر ادامه دادیم، فقط با خواندن `docs/` کل پروژه دستمان بیاید.

## پروژه چیست؟

**ایستگاه دندان** (`istgahedandan.ir`) یک دایرکتوری و مرجع آنلاین دندانپزشکان و کلینیک‌های دندانپزشکی ایران است. سایت کاملاً فارسی و RTL است.

سه گروه کاربر دارد:

| گروه | چه می‌کند | مسیر ورود |
|---|---|---|
| **بازدیدکننده (بیمار)** | جستجوی دندانپزشک بر اساس منطقه/خدمت، دیدن پروفایل، نقشه، خواندن مقالات، ثبت نظر، **رزرو آنلاین نوبت** | `/` |
| **دندانپزشک** | مدیریت پروفایل مطب، برنامه نوبت‌دهی، دیدن نوبت‌ها، استوری، گالری، ویدیو، نوشتن مقاله | `/dentist/panel` |
| **ادمین** | مدیریت کامل دندانپزشکان، مناطق، خدمات، بلاگ، نظرات، کاربران، تنظیمات | `/admin` |

سایت از یک نسخهٔ قدیمی **وردپرس** مهاجرت داده شده. آثار آن هنوز در کد هست:
- تقریباً همهٔ مدل‌ها فیلد `wpPostId` / `wpTermId` / `wpCommentId` دارند (برای جلوگیری از ایمپورت تکراری).
- در `next.config.ts` یک rewrite از `/wp-content/uploads/*` به `/uploads/*` هست تا لینک‌های قدیمی نشکنند.
- اسلاگ‌های فارسی (مثل `/قوانین-و-مقررات`) از وردپرس مانده‌اند و همان ساختار flat URL حفظ شده (بخش معماری).

## تکنولوژی

| لایه | انتخاب |
|---|---|
| فریم‌ورک | **Next.js 16.2.9**، App Router |
| React | 19.2.4 |
| زبان | TypeScript |
| دیتابیس | PostgreSQL (پورت `5436` طبق `docker-compose.yml`) |
| ORM | **Prisma 7** با driver adapter `@prisma/adapter-pg` |
| احراز هویت | JWT دستی با `jose` + کوکی `httpOnly`، هش پسورد با `bcryptjs` |
| استایل | **inline style** — تقریباً هیچ CSS یا Tailwind استفاده نمی‌شود |
| فونت | `Vazirmatn` از `next/font/google` |
| ویرایشگر متن | TipTap 3 (`src/components/admin/RichEditor.tsx`) |
| نقشه | Leaflet + `leaflet.markercluster` (بدون کلید API) |
| تاریخ شمسی | `jalaali-js` |

> ⚠️ **Next.js 16 با نسخه‌ای که در حافظهٔ مدل‌هاست فرق دارد.** طبق `AGENTS.md` قبل از نوشتن کد، راهنمای مربوطه را از `node_modules/next/dist/docs/` بخوانید. مهم‌ترین تفاوت‌هایی که در همین پروژه دیده می‌شود:
> - `middleware.ts` حذف شده؛ جایش **`src/proxy.ts`** با تابع `proxy()` است.
> - `params` در صفحات و route handlerها **Promise** است و باید `await` شود.
> - `cookies()` async است.
> - Route Handlerها به‌صورت پیش‌فرض cache نمی‌شوند.

## راه‌اندازی محلی

```bash
cp .env.example .env             # DATABASE_URL و JWT_SECRET را پر کنید
docker compose up -d             # PostgreSQL روی پورت 5436
npx prisma migrate deploy
npx tsx scripts/seed.ts          # داده اولیه
npx tsx scripts/create-admin.ts  # ساخت کاربر ادمین
npm run dev
```

اسکریپت‌های کمکی در `scripts/`:

| فایل | کار |
|---|---|
| `seed.ts` | داده اولیه |
| `create-admin.ts` | ساخت `AdminUser` |
| `import-reviews.ts` | ایمپورت نظرات از وردپرس |
| `extract-phones.ts` | استخراج شماره تلفن از متن پروفایل‌ها |

دستورات روزمره: `npm run dev` · `npm run build` · `npm run start` · `npx tsc --noEmit`

> `npm run lint` در حال حاضر با ۱۶ خطای از پیش موجود شکست می‌خورد (مسئلهٔ ۲۲ در [`03-issues.md`](./03-issues.md)). دروازهٔ کیفیت فعلی `tsc --noEmit` و `next build` است.

## دیپلوی و داده

سایت روی <https://istgahedandan.ir> زنده است. دیپلوی با `./scripts/deploy.sh` انجام می‌شود — جزئیات کامل در [`05-deploy.md`](./05-deploy.md).

**دیتابیس پروداکشن مرجع رسمی داده‌هاست.** محتوا (مقالات، دندانپزشکان، خدمات، صفحات) از پنل ادمین سایت به‌روز می‌شود. دیتابیس محلی صرفاً محیط دمو و توسعه است و انتقال داده از لوکال به پروداکشن انجام نمی‌شود.

## متغیرهای محیطی

| کلید | کاربرد |
|---|---|
| `DATABASE_URL` | اتصال PostgreSQL |
| `JWT_SECRET` | امضای توکن **هم ادمین و هم دندانپزشک**. اجباری، حداقل ۳۲ کاراکتر |
| `NEXT_PUBLIC_SITE_URL` | مبنای canonical / sitemap / JSON-LD |
| `NEXT_PUBLIC_SITE_NAME` | نام سایت |
| `SHADOW_DATABASE_URL` | اختیاری، فقط برای ابزار توسعه: `prisma migrate dev` و بررسی هماهنگی migrationها |

`JWT_SECRET` **fallback ندارد** — اگر ست نشده یا کوتاه‌تر از ۳۲ کاراکتر باشد، `src/lib/jwt-secret.ts` در زمان اجرا خطا پرتاب می‌کند. این عمدی است: یک مقدار پیش‌فرض داخل مخزن یعنی یک دیپلوی بدتنظیم با کلیدی عمومی توکن امضا می‌کند. تولید مقدار مناسب: `openssl rand -base64 48`

هر دو خانوادهٔ توکن با همان کلید امضا می‌شوند، پس payload یک claim `role` (`"admin"` / `"dentist"`) دارد که هنگام تأیید بررسی می‌شود.

## قواعد کدنویسی پروژه

این‌ها قرارداد نانوشتهٔ کدبیس‌اند؛ کد جدید باید با همین‌ها بخواند:

- **استایل inline** با `style={{ ... }}`. پالت ثابت:
  - فیروزه‌ای اصلی: `#0c8aa6` / `#15b8d1` / `#0b6e8a`
  - گرادیان اکشن: `linear-gradient(135deg,#15b8d1,#0a6f9e)`
  - متن تیره: `#133b48` / `#2a4f5b` — متن کم‌رنگ: `#8aabb5`
  - پس‌زمینهٔ پنل: `#f4f9fb` — بوردر ملایم: `#e7f0f3` / `#dceaef`
  - فوتر: گرادیان `#0e4151 → #0a2c39`
  - شعاع گردی: کارت‌ها ۱۲–۲۴ پیکسل
- ریشهٔ هر صفحه `direction: "rtl"` و `fontFamily: "inherit"` می‌گیرد.
- آیکون‌ها **inline SVG** با `stroke="currentColor"` هستند، نه کتابخانهٔ آیکون.
- همهٔ متن‌های UI و پیام‌های خطا فارسی‌اند.
- Server Component پیش‌فرض است؛ `"use client"` فقط جایی که state/effect لازم است.
- API routeها همیشه `NextResponse.json({ error: "پیام فارسی" }, { status })` برمی‌گردانند.
- اعداد نمایشی با `toPersian()` از `src/lib/utils.ts` فارسی می‌شوند و تاریخ‌ها با `toJalali()`.

## خلاصهٔ خیلی کوتاه

**ایستگاه دندان** یک دایرکتوری فارسی/RTL دندانپزشکان ایران است روی **Next.js 16 (App Router) + React 19 + Prisma 7 + PostgreSQL**، مهاجرت‌داده‌شده از وردپرس. سه سطح کاربر دارد: بازدیدکننده، دندانپزشک (`/dentist/panel`)، ادمین (`/admin`). قابلیت شاخصش **رزرو آنلاین نوبت** با تقویم شمسی است. کل UI با **inline style** نوشته شده، نه CSS یا Tailwind.

⚠️ **این نسخهٔ Next.js با آنچه در حافظهٔ مدل‌های زبانی است فرق دارد** — قبل از نوشتن کد، راهنمای مربوطه را از `node_modules/next/dist/docs/` بخوانید. مثلاً `middleware.ts` وجود ندارد و جایش `src/proxy.ts` است.

سایت روی <https://istgahedandan.ir> زنده است و **دیتابیس پروداکشن مرجع رسمی داده‌هاست** — محتوا از پنل ادمین به‌روز می‌شود، نه با انتقال از لوکال.
